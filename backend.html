Elyan Backend System

Elyan backend artık sadece ince bir chat proxy değil; auth, billing, realtime, routing, memory, dialogue state, telemetry, learning events ve server-brain agent foundation yöneten data-first control-plane katmanıdır.

Ana ilke: düz metin son yüzeydir, arka planda tipli veri çalışır.

What Changed Recently

Server-Owned Dialogue State

`dialogue_states` tablosu eklendi. State artık server tarafından damgalanır ve session/user owner doğrulaması olmadan prompt'a girmez.

Cross-User Leak Fix

Mobil cache kaynaklı `compactContext/userMemory/recentMessages` artık authoritative değildir. Başka user/session metadata'sı prompt, continuity veya fallback state'e alınmaz.

Turn Metrics

`turn_metrics` fire-and-forget telemetry eklendi. Prompt/private content yazmadan latency, block, fallback, tool ve quality sinyalleri ölçülür.

Memory Fabric Direction

Preferred-name gibi tek değerli memory key'lerinde en son açık kullanıcı isteği kazanır; stale alias prompt'a karışmaz.

Agent Tool Foundation

`tool-registry` ve sınırlı `agent-loop` eklendi. `web.search`, `memory.query`, `memory.write`, `goals.update` typed tool olarak paketlenmeye başladı.

Proactive Foundation

`proactive_triggers` ve user proactive prefs temeli eklendi. Follow-up, mute, daily cap ve quiet-hour policy veriyle yönetilecek.

Canonical Data Stores

users / auth_identities

Account, social identity, deletion and ownership truth.

devices / pair_sessions

Mobile/desktop registration, pairing and runtime heartbeat truth.

chat_sessions / messages

Conversation surface, assistant blocks and SSE replay truth.

brain_memory_facts

User-scoped facts, preferences, corrections and memory fabric source.

dialogue_states

Canonical per-session state: goal, stage, loops, style, user memory and tool history.

turn_metrics

Non-blocking latency and quality telemetry for every brain turn.

session_goals / goal_events

Goal loop state and append-only progress history.

proactive_triggers

Future follow-ups, reminders and task nudges.

learning_events / artifacts

Approved correction dataset and Elyan model learning pipeline input.

Security Boundary
User Scope Is MandatoryEvery memory/state/context path must be scoped by authenticated `userId`; session-scoped data must also match `sessionId` when available.
Client Cache Is UntrustedClient metadata can be a hint only. Server-owned state must carry `server_dialogue_state.v1` and matching owner fields.
No Private Local ExecutionBackend never controls the user's computer directly. Private execution stays on desktop runtime behind permissions.
No Provider DisclosureProvider/model/system prompt names are sanitized from visible replies and benchmarked for leak rate.
